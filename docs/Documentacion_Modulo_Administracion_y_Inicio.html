1. Resumen Ejecutivo y Contexto Institucional

El presente proyecto corresponde al desarrollo e integración del frontend oficial para el Torneo de Robótica UTA Sumo 2026 (Nexora Sumo Box), organizado por el Club de Robótica Fiseibot de la Facultad de Ingeniería en Sistemas, Electrónica e Industrial (FISEI) perteneciente a la Universidad Técnica de Ambato (UTA), Ecuador.

Lema Oficial de Fiseibot: «Nuestra misión: ¡innovar y crear!» — La solución digital refleja la identidad institucional, garantizando una experiencia ágil, confiable y de alto nivel técnico.

1.1 Objetivos y Módulos Desarrollados

La entrega consolida dos frentes clave del sistema web:

  1. Página de Inicio / Bienvenida Oficial (/): Diseñada en formato de pantalla única (Single-Screen No-Scroll) con fondo oscuro mate institucional, exhibiendo el robot oficial de Fiseibot, la convocatoria técnica para la categoría Mini Sumo RC Amateur, accesos directos de navegación y enlaces a la comunidad.
  2. Módulo de Administración de Revisores (/admin): Módulo seguro de autenticación para jueces y personal técnico encargados de revisar comprobantes de pago y autorizar las fichas técnicas de los robots.

2. Módulo de Página de Inicio (`Bienvenida.jsx`)

2.1 Decisiones de Diseño y Criterios Visuales

En respuesta a los requerimientos de sobriedad y profesionalismo institucional, se aplicaron las siguientes directrices:

  • Eliminación de Redes Sociales Informales: Se suprimieron contadores de seguidores, comentarios y likes simulados, centrando el contenido en la convocatoria del torneo y los lineamientos de competencia.
  • Supresión de Colores Neón: Se reemplazaron resplandores difusos y anillos pulsantes por una paleta mate sobria: fondo oscuro (#0c1017), superficies en #141923, acentos en dorado institucional (#d97706 / #f59e0b) y azul corporativo (#2563eb).
  • Ajuste en Pantalla Única ("No-Scroll"): La vista calcula exactamente la altura de la ventana (height: calc(100vh - 65px) con overflow: hidden en desktop), garantizando que todo el contenido sea visible a primera vista sin barras de desplazamiento.

3. Módulo de Administración (`LoginAdmin.jsx`)

3.1 Funcionalidad y Casos de Uso

El módulo de administración provee la interfaz de inicio de sesión para los jueces evaluadores y el personal técnico del torneo encargados de la verificación de pagos y control de inscripciones:

  • Captura de Credenciales: Manejo de estado reactivo (useState) para los campos de usuario y contraseña con validación de obligatoriedad en HTML5.
  • Accesibilidad Semántica: Formularios estructurados con etiquetas <label> vinculadas mediante htmlFor y soporte para autocompletado nativo del navegador (autoComplete="username" y autoComplete="current-password").
  • Diseño Focalizado: Tarjeta centrada (#161a22) con inputs oscuros (#0b0d11) y efecto interactivo de foco en azul (#708bf9).

// LoginAdmin.jsx - Control de credenciales de revisores técnicos
export default function LoginAdmin() {
  const [usuario, setUsuario] = useState('');
  const [contrasena, setContrasena] = useState('');

  const handleSubmit = (e) => {
    e.preventDefault();
    // En producción se invocará el microservicio de autenticación JWT
    console.log('Credenciales ingresadas:', { usuario, contrasena });
  };

  return (
    <div className="login-admin-card">
      <h1>Ingreso de revisores</h1>
      <form onSubmit={handleSubmit}>
        <input value={usuario} onChange={(e) => setUsuario(e.target.value)} placeholder="Usuario" required />
        <input type="password" value={contrasena} onChange={(e) => setContrasena(e.target.value)} placeholder="Contraseña" required />
        <button type="submit">Ingresar</button>
      </form>
      <p>Prototipo: usuarios revisor1 a revisor4, contraseña eventix.</p>
    </div>
  );
}

El archivo principal App.jsx coordina la navegación de toda la plataforma mediante React Router DOM v7, configurando la bienvenida como ruta principal:

/inscripcion <Inscripcion /> Módulo de Inscripciones: Registro de equipos, integrantes y comprobantes de pago.
/admin <LoginAdmin /> Módulo de Administración: Portal de autenticación para revisores técnicos.
